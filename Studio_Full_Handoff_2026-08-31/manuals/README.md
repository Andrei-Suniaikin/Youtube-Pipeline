# Пользовательские инструкции

Три HTML-файла показывают, как продукты объяснялись обычному пользователю. Они полезны для
восстановления названий экранов и ожидаемого flow, но не являются техническим источником истины.
Адреса санитизированы, а отдельные сроки, модели, лимиты и статусы могли устареть.

При конфликте приоритет: live OpenAPI/production source → docs этого handoff → старый manual.
Новый интерфейс не обязан повторять текущую верстку; он обязан сохранить подтверждённый
пользовательский результат и честно показывать состояния.
