# ops-manga — правки конвейера манхвы

Боевой конвейер манхвы живёт на VPS в `/root/manga_rewrite/app` (чужой production:
запись только со слова владельца и с резервной копией). Здесь — копии файлов, которые
мы правим, чтобы было видно, что именно поменяли.

Первый коммит каждого файла — побайтовая копия боевого (sha256 сверен с машиной),
дальше — наши правки поверх. Выкатка: резервная копия на машине → `scp` → sha256 до и
после.

| Файл | Боевой sha256 до правок |
|---|---|
| `align.py` | `302ebb6c1dc2…` |
| `voice_fastgen.py` | `710a13dea89a…` |
