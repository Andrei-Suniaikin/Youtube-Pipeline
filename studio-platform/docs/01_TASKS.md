## Утром — пять минут

1. `@BotFather` → `/newbot` → токен.
2. Написать боту любое сообщение (или добавить его в группу).
3. `cp .env.example .env`, вписать `VS_TG_TOKEN=`.
4. `.venv/bin/python dev/alerts.py --whoami` → покажет `chat_id`, вписать `VS_TG_CHAT=`.
5. `.venv/bin/python dev/alerts.py --test` → должно прийти сообщение.

После этого `dev/run.sh` сам поднимет цикл тревог рядом с сервисами.

**Про лимиты Telegram.** Bot API бесплатен. Ограничения: около 30 сообщений в секунду
суммарно, не чаще одного в секунду в один чат, и не больше **20 в минуту в групповой
чат** — это и есть та цифра, что попадалась. Наши тревоги: шесть поводов, каждый не
чаще раза в час, плюс «починилось». Потолок — примерно 12 сообщений в час. В лимиты
мы не упираемся даже близко.

## Осталось

### A. Не блокировано, можно делать сразу

| № | Задача | Объём | Почему это нужно |
|---|---|---|---|
| A1 | Вкладку тревог перевести с ручного цикла на systemd-таймер | 0,5 дня | сейчас цикл живёт только пока запущен `dev/run.sh` |
| A2 | Экран входа и разделение прав | 2–3 дня | пульт сейчас без авторизации вообще |
| A3 | Действия в строке очереди: отмена, повтор, приоритет | 2 дня | ТЗ §13; читать умеем, управлять — нет |
| A4 | Форма нового выпуска: выбор пресета и языка | 2 дня | сейчас в форме только ссылка и канал |
| A5 | Экран выпуска: кнопки повтора одной стадии | 2 дня | ТЗ §14; повтор кадра не должен трогать соседние |
| A6 | Подключить к журналу оставшиеся платные пути: клипы (Veo), рерайт | 2–3 дня | три движка из пяти подключены |
| A7 | Поздняя проверка «ролик стал публичным» | 2 дня | ТЗ §11; `done` сегодня ≠ опубликовано |

### B. Честные долги журнала платных вызовов

| № | Долг | Почему не закрыт |
|---|---|---|
| B1 | У синхронных провайдеров нет идентификатора заказа | окно между отправкой и ответом не закрыть без idempotency key на их стороне — нужно спросить провайдеров |
| B2 | `cost` всегда пуст | провайдеры не возвращают подтверждённую цену; сумма по проекту пока не считается |
| B3 | В параллельном режиме по URL `result_path` пуст | путь становится известен позже записи |
| B4 | В Cover `delivered()` срабатывает до записи на диск | «готово» доказывается файлом — здесь пока доказывается ответом |

### C. Блокировано решением владельца

| № | Задача | Чего ждём |
|---|---|---|
| C1 | Слияние Cover в единый веб | **где живёт список пользователей** после объединения |
| C2 | Слияние Rewrite в единый веб | то же самое |
| C3 | Убрать `pub_neighbors.py` (чтение чужих SQLite) | то же самое; путь к пресетам уже честный, остались пользователи |
| C4 | Включить уборку диска | **сроки хранения**: через сколько дней после публикации чистить промежуточное и через сколько удалять проект |

C1–C3 — это один вопрос, а не три. Три сервиса опознают человека по-разному, а
`pub_neighbors` сшивает их сравнением логинов. Пока не решено, кто хозяин списка
пользователей, любое объединение либо ломает партнёров (`tenant_id` в `main.py`
встречается 141 раз), либо показывает всем пресеты владельца общего ключа.

C4 не требует кода — механизм готов и ждёт двух чисел.
