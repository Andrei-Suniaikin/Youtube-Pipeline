# Тревоги в телеграм — что нужно сделать

Система будет писать в телеграм, когда конвейер встал: очередь не двигается,
провайдер на паузе, ролики не заливаются, слот прошёл без ролика, кончается диск.
Плюс отдельным сообщением — когда починилось.

Нужны две строки: токен бота и id чата. Пять минут.

## 1. Завести бота

В телеграме найти **@BotFather** → `/newbot` → ответить на два вопроса
(имя и username, username должен заканчиваться на `bot`).

В ответ придёт строка вида:

```
123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
```

Это **токен**. Он даёт полный доступ к боту — не пересылать в открытые чаты
и не класть в репозиторий.

## 2. Решить, куда бот пишет

**Личные сообщения** — просто написать боту любое сообщение (например `/start`).

**Группа** (если тревоги должны видеть несколько человек) — создать группу,
добавить туда бота и написать в неё любое сообщение.

Без этого шага бот не сможет никому написать первым: в телеграме нельзя начать
переписку с человеком, который сам не написал боту.

## 3. Узнать id чата

Открыть в браузере, подставив свой токен:

```
https://api.telegram.org/bot<ТОКЕН>/getUpdates
```

В ответе найти `"chat":{"id":...}`. Личный чат — положительное число,
группа — отрицательное, начинается на `-100`.

## 4. Прописать в окружение

Две переменные там же, где живут остальные настройки сервиса
(`.env` рядом с кодом либо `EnvironmentFile` юнита systemd):

```
VS_TG_TOKEN=123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
VS_TG_CHAT=-1001234567890
```

Проверка, что связь есть:

```bash
.venv/bin/python dev/alerts.py --test
```

Должно прийти сообщение «Проверка связи». Если не пришло — команда напечатает,
что именно не так.

## Что важно знать

**Ничего не стоит.** Bot API бесплатен. Лимиты — 20 сообщений в минуту в группу;
у нас шесть поводов, каждый не чаще раза в час, потолок около 12 сообщений в час.

**Пока переменных нет, система работает как раньше** — просто молчит. Тревоги
всё равно определяются и видны на экране «Админ», отметкой «ещё не сказано».

**Токен можно отозвать в любой момент** — @BotFather → `/revoke`. Старый перестаёт
работать сразу.
