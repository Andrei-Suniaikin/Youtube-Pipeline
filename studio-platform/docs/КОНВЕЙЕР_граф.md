# Конвейер: что чего ждёт на самом деле

Документ для обсуждения. Сначала факт — как устроено сейчас, потом предложение,
потом вопросы, на которые нужен ответ владельца.

---

## Как есть сегодня

В системе живут **два разных конвейера**, и они не совпадают.

### А. Ручной, в кабинете — кнопка «весь конвейер»

```
        ┌─► озвучка ──┐
текст ──┤             ├─► [вотчер] ─► видео ─► [вотчер] ─► рендер
        └─► картинки ─┘
```

Озвучка и картинки ставятся сразу вместе. Видео и рендер отложены флагами, вотчер
запускает их по мере готовности материалов. Это правильная схема, и она работает.

### Б. Автоматический, движок выпусков

```
ссылка ─► текст ─► проект ─► [озвучка ∥ картинки] ─► рендер ─► ОБЛОЖКА ─► заливка
                                                                 ↑
                                          ждала здесь часами без всякой причины
```

Отличия от ручного, все не в пользу автоматического:

| | Ручной | Движок выпусков |
|---|---|---|
| Озвучка ∥ картинки | да | да |
| Клипы (видео) | да, вотчером | **нет вообще** |
| Обложка | отдельно, руками | ждала весь рендер (**исправлено 04.09**) |

`MEDIA_STAGES` движка — это `tts, images, render, chapters`. Слова `video` там нет.
То есть **выпуски не умеют делать ролики с клипами** — только слайд-шоу из кадров.

### Мёртвое, найденное по дороге

`pub_channels.video_mode` — колонка есть, значение по умолчанию `slideshow`,
**не читает никто**. Канал как бы объявляет, каким должен быть ролик, и это объявление
никуда не доходит. `t2v_first_n` читается, но из параметров задачи, а не из канала.

## Настоящие зависимости

Что чему нужно на входе — по коду, а не по привычке:

| Шаг | Нужен вход | Значит может начаться |
|---|---|---|
| Обложка | донорская ссылка | сразу |
| Текст | субтитры донора | сразу |
| Проект | текст | после текста |
| Озвучка | текст | после текста |
| Кадры | сцены (из текста) | после текста |
| Клипы **i2v** | готовые кадры | после кадров |
| Клипы **t2v** | сцены (из текста) | **после текста, кадры не нужны** |
| Рендер | озвучка + кадры (и клипы, если они есть) | после них |
| Заливка | рендер + обложка | после обоих |

## Предлагаемый граф

```
ссылка ──┬──────────────────────────► обложка ──────────────────┐
         │                                                      │
         └─► текст ─► проект ─┬─► озвучка ───────────────┐      │
                              │                          │      │
                              ├─► кадры ─┬─► клипы i2v ──┤      │
                              │          └───────────────┤      │
                              │                          ├─► рендер ─► заливка
                              └─► клипы t2v ─────────────┘
```

Критический путь: **текст → кадры → рендер**. Всё остальное успевает рядом.

Что это даёт по времени. Обложка делалась минуты после часов ожидания — теперь рядом.
Клипы t2v не ждут кадров вообще: при 155 кадрах это экономит весь этап картинок для тех
каналов, где ролик собирается из клипов.

## Вопросы, на которые нужен ответ

### 1. Нужны ли клипы в автоматических выпусках?

Сегодня ролики выпусков — всегда слайд-шоу из кадров. Клипы делаются только вручную.

- **а)** не нужны — оставляем как есть, `video_mode` удаляем как мёртвую настройку;
- **б)** нужны на части каналов — оживляем `video_mode` и выбираем режим в канале;
- **в)** нужны везде.

Ответ определяет, сколько работы: (а) — ноль, (б) — два-три дня, (в) — день.

### 2. Если нужны — i2v или t2v?

- **i2v** (клип из готового кадра) — дороже и дольше: сначала кадр, потом клип из него.
- **t2v** (клип прямо из описания сцены) — быстрее и параллельнее, но кадра не будет
  вовсе, а кадры нужны для обложки-заглушки и для добивки, если клип не вышел.

Возможен смешанный: первые N сцен клипами, остальное кадрами — под это и заведён
`t2v_first_n`.

### 3. Рендер ждёт клипы или начинает без них?

Если клип одной сцены не получился (у Veo это штатно — контент-фильтр), что делать:

- **а)** подставить на его место кадр и рендерить (нужен и кадр, и клип);
- **б)** ждать добивки, задерживая ролик;
- **в)** рендерить без этой сцены.

Сейчас в ручном конвейере клипы опциональны: рендер идёт по тому, что есть.

### 4. Что делать со сроками параллельных веток

Сейчас у фазы производства один срок на всё — шесть часов. С ветками разумнее свой
срок каждой: обложка не должна съедать терпение, отведённое рендеру, и наоборот.

Предложение: обложка — 30 минут, озвучка — час, кадры — три часа, клипы — три часа,
рендер — два часа. Это не гадание, а запас над медианой, но подтвердить надо по факту.

### 5. Падение одной ветки — что с остальными?

Сейчас: любая ошибка этапа отправляет выпуск в карантин.

Предложение по веткам:

| Ветка | Упала |
|---|---|
| Текст | выпуск в карантин — без текста ничего не будет |
| Озвучка | карантин |
| Кадры | карантин |
| Клипы | продолжаем без них, если есть кадры |
| Обложка | продолжаем, ролик заливается без обложки — **или нет?** |
| Главы | продолжаем (уже так) |

Строка про обложку — вопрос: заливать ролик без обложки или держать до починки?
Обложка влияет на просмотры, но задержка публикации тоже.
