Пресет ниши

Пресет хранит постоянные правила канала: стиль, композицию, референс, модель и число обложек.

Пресет не выбран

Импорт открывает JSON в редакторе — проверьте поля и нажмите «Сохранить». Экспорт скачивает настройки без самой картинки референса.

Семена

Семя описывает конкретную обложку: текст, главный объект, сцену и композицию. Для каждого языка — отдельная строка.
