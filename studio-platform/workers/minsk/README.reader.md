# Studio reader на Минске

`studio_reader.py` — читатель часов, монетизации и доступности функций YouTube Studio,
который вызывается внешним сборщиком `collector.py`.
Рабочий путь: `/home/vova/adspower_audit_20261004/studio_reader.py`.

Исходная production-копия от 4 октября 2026:
`51b0e0dbb3ee5d3ea14061b5afc7f8c19d668f9f5b7a0c46a76f76b6d58ed7b6` (SHA-256).

Два частых вызова скриншота используют CDP `Page.captureScreenshot` с
`fromSurface: true`. Это убирает активацию окна командой WebDriver screenshot.
Первоначальное открытие профиля AdsPower всё ещё может активировать окно.
Способ навигации, проверки владельца/брони и чтение данных сохранены.

Проверка из корня репозитория, только стандартная библиотека, без живых браузеров:

```sh
python3 -m unittest discover -s studio-platform/tests -p test_earn_reader_screenshots.py -v
```

Деплой выполняется отдельно, только для `studio_reader.py`:

1. Дождаться отсутствия работающего `collector.py` и заблокировать новые задания
   на время замены. Не заменять модуль во время сбора.
2. Проверить SHA-256 рабочего файла: он должен совпадать с проверенной базой выше
   (при последующих обновлениях — с последним подтверждённым деплоем). При расхождении
   остановиться и сверить изменения; не затирать чужой код.
3. Сделать `cp -p` рабочего файла в резервную копию с уникальным временем в имени.
   Загрузить новый файл во временный файл в том же каталоге, проверить его SHA-256
   против Git-копии и компиляцию Python.
4. Повторно проверить исходный SHA-256 и отсутствие сборщика, затем выполнить
   атомарную замену через `os.replace`. Сохранить SHA-256 новой версии в отчёте.
5. Проверить один штатный сбор: полный результат, скриншоты и сохранение фокуса.
   При откате так же дождаться отсутствия сборщика и атомарно вернуть резервную копию.

Рабочий `earn_puller.py` отличается от снимка в этом репозитории.
**Не разворачивать `earn_puller.py` из репозитория вместе с reader**.
